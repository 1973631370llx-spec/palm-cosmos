# 掌心宇宙 / PALM COSMOS

> 摊开手，是一整个宇宙；握紧，它为你坍缩。

一团星系停在掌心：手怎么动，星系就怎么跟。握拳，粒子螺旋坍缩成吸积盘、纯黑事件视界和一圈引力透镜光环；再张开，超新星爆发——冲击波、径向爆发、暖白闪光，然后余波散去。

**双手就是两个星系**：两只手各托一团，靠近到一定距离会合并爆发；拇指和食指捏合会收紧成引力透镜；单指指出去，指尖那颗星会被点亮成星轨。

纯静态：没有构建、没有后端、运行时不请求任何外网资源。Three.js r169 与 MediaPipe HandLandmarker 全部在 `vendor/` 本地，摄像头画面只在本机处理。

手机、电脑都能跑（手机横竖屏都适配）。想发给别人玩，见下面的「分享给别人」。

## 分享给别人（一条公网 HTTPS 链接）

```powershell
cd palm-cosmos
powershell -ExecutionPolicy Bypass -File tools\share.ps1
```

脚本会：起本地服务 → 起 Cloudflare 隧道（`cloudflared`，无需账号）→ 打印一条 `https://xxx.trycloudflare.com` 网址 → 生成二维码到 `shots/share-qr.png`。

- 手机、电脑直接打开，**扫码也行**；摄像头只要求 HTTPS，这个地址满足
- 第一次打开要下载手部模型（约 8MB），页面右下角会显示进度提示；之后浏览器缓存，秒开
- 关掉电脑或隧道进程，网址就失效；重新运行脚本会拿到**新的**网址
- 只在自己电脑上试：`node server.mjs` → `http://127.0.0.1:4173/`（离线、不联网）

> 隧道地址走的是这台机器的上行带宽，几个人同时打开会互相抢带宽。要长期稳定，建议传到任意静态托管（Cloudflare Pages / Netlify / Vercel / GitHub Pages），整个目录直接上传即可，无需构建。

## 运行

```bash
cd palm-cosmos
node server.mjs
```

打开 **http://127.0.0.1:4173/**

常用地址：

| 地址 | 用途 |
| --- | --- |
| `http://127.0.0.1:4173/` | 正常入口（开启掌心 / 无摄像头体验） |
| `http://127.0.0.1:4173/?demo=1` | 自动循环「托起 → 握拳 → 爆发」，录屏用 |
| `http://127.0.0.1:4173/?debug=1` | 显示 FPS、端到端延迟、21 点骨架、掌心锚点、手数 |
| `http://127.0.0.1:4173/?count=8000` | 强制粒子数（1000–16000），低配机 / 压测用 |
| `http://127.0.0.1:4173/?cdn=1` | wasm / 模型改走公共 CDN（首次加载更快，需要外网） |

`server.mjs` 零依赖，默认 `127.0.0.1:4173`，可改端口：

```bash
node server.mjs --port 8080 --host 0.0.0.0
```

> 摄像头需要安全上下文：`127.0.0.1` / `localhost` / `https` 都行。手机访问请用 HTTPS 或把手机与电脑放在同一局域网并用 `--host 0.0.0.0` + 反向代理的 https。

## 操作

**掌心模式（开启掌心）**

| 手势 | 反应 |
| --- | --- |
| 张手 | 星系舒展、缓慢自转；五指各挂一颗星，逐帧跟随指尖 |
| 握拳 | 坍缩成黑洞（ease-in 1.2 s），吸积盘只剩边缘光，中央纯黑视界 |
| 握拳后快速张开 | 超新星（冷却 2 s）：冲击波 0.4 s + 余波 2.4 s |
| 拇指 + 食指捏合 | 引力透镜：星系收紧成一个亮环、中心开始变暗，但**不**出现视界；松开即回弹 |
| 食指单指指出 | 那颗指尖星变亮、拖尾拉长（星轨） |
| 两只手 | 两团星系（第二团偏品红）、10 颗指尖星；两掌靠近 < 0.8 → 合并爆发（两圈冲击波、双倍闪光） |
| 手离开画面 | 保持最后姿态 0.8 s，再回待机；重新入画 0.2 s 内接上 |

前置摄像头水平镜像（像照镜子）。

**指针模式（无摄像头体验）**

- 指针位置 = 掌心；按住 = 坍缩；松开 = 爆发
- `← ↑ ↓ →` 移动，`Space` 按住 / 松开，`Esc` 打开面板

- 色板只有五个：背景 `#030409`、靛蓝 `#2A3BFF`、品红 `#FF3D81`、青 `#35E0D0`、暖白 `#FFF6E8`

## 实时跟随是怎么做的

- 每帧读取 21 个 landmark（含 `worldLandmarks` 与 handedness），最多两只手，按镜像后的屏幕位置左→右排序
- 掌心 = landmark 0 与 9 的中点 → 星系世界坐标锚点；位移 ×1.15 轻微夸张
- 手离镜头距离（landmark 9 的 z）与掌宽 → 大小 0.8–2.0×（再 ×1.2）；双手时各自 ×0.74，画面不挤
- 掌面 roll / yaw / pitch → 盘面倾角
- 锚点用 SmoothDamp 临界阻尼跟随（k=0.12、无过冲、带速度上限）：不橡皮筋、不来回晃；快速移动时刚度自动上调到 ~0.34，追得更紧
- **速度外推 45 ms**：用掌心速度把目标点往前推（上限 0.35 世界单位），抵消识别延迟，快速移动不"拖影"
- 指尖星用 One Euro Filter（minCutoff 1.2 / beta 0.02）：慢速不抖、快速不拖
- `requestVideoFrameCallback` 对齐视频帧，仅在出现新帧时推理一次
- 丢失保持 0.8 s 最后姿态，再回待机

### 为什么快速移动不卡

1. 输入分辨率降到 **640×360**：GPU delegate 单次识别 **6.3 ms**（原来 960×540 是 13.5 ms）
2. 逐帧更新路径**零分配**：不再每帧 `new Vector3` / 数组拷贝（指尖轨迹改环形缓冲），去掉 GC 抖动
3. 引爆前先 `renderer.compile()` + 预渲染一帧：冲击波、指尖星、Bloom 的 shader 全部预编译，爆发瞬间没有编译卡顿
4. 跟随换成 SmoothDamp 临界阻尼：以前那套弹簧在大幅移动时会冲到目标外 2 倍再荡回来（就是"飘/橡皮筋"），现在单调收敛
5. 识别只在新视频帧上跑；每只手独立弹簧，互不拖累
6. GPU 不可用时（退回 CPU）自动把识别挪进 Worker（`js/hand-worker.js`），主线程继续 60 fps；Worker 2.5 s 无响应会自动切回主线程

## 性能

- 桌面 12000 粒子 × 最多 2 团 / 手机 7000（`?count=8000` 可压到 8000）
- WebGL2，DPR 桌面 ≤ 1.5、手机 ≤ 1.25，Bloom 之后 `OutputPass` 做色调映射
- 每团星系 3 个 draw call（粒子 + 盘面 + 核心辉光），几何全部在 GPU 上算；第二团不可见时不提交
- 页面隐藏时暂停 rAF；`prefers-reduced-motion` 下降低自转、减弱闪光与镜头抖动
